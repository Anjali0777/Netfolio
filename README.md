# ANJALI — Netfolio

Netflix-style portfolio of **Anjali Gupta**, software engineer building AI applications, full-stack systems and data pipelines.

The entire site is one self-contained `index.html`: styles, scripts, photos, the intro sound and the résumé PDF are all embedded, so it runs anywhere with no build step.

## Features
- Cinematic intro with sound, synced to the animation
- Experience as an episode list, project grid with filters, Top 10 results
- Search (Ctrl/⌘ K), "My List" saved in the browser, one-click résumé download
- Responsive down to phone width, keyboard accessible

## Publish with GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root. The site appears at `https://anjali0777.github.io/netfolio/`.
